# CCTV Viewer for Home Assistant

This repository is the public Home Assistant catalog for CCTV Viewer. It
contains only installable app metadata and release history; application source,
tests and container definitions live in
[`cctv-timeline-viewer-core`](https://github.com/robertoamd90/cctv-timeline-viewer-core).

## Installation

1. Open **Settings > Apps > App store > Repositories**.
2. Add:

   ```text
   https://github.com/robertoamd90/cctv-timeline-viewer
   ```

3. Install **CCTV Viewer**, start it and enable **Show in sidebar**.
4. Add cameras using directories available under Home Assistant `/media`.

Network storage must first be configured in Home Assistant as Media storage.
CCTV Viewer receives `/media` read-only and never mounts SMB or NFS shares
itself.

## Release Channels

- **CCTV Viewer** is the stable channel.
- **CCTV Viewer Beta** receives release candidates and uses separate app data,
  so it can be installed alongside stable.

Both channels use prebuilt multi-architecture images for `amd64` and `aarch64`.
The catalog version is changed only after the matching GHCR image has been
published and inspected.

## Repository Scope

```text
repository.yaml       Home Assistant repository metadata
cctv_viewer/          Stable app metadata and documentation
cctv_viewer_beta/     Beta app metadata and documentation
release-state.json    Published image provenance
```

Catalog commits are generated by the release pipeline. Product development and
release tags are managed in the
[source repository](https://github.com/robertoamd90/cctv-timeline-viewer-core).
